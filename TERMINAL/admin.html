📊 Data Storage

All data is stored locally in the browser's localStorage. This means:

  • Each visitor sees their own local stats
  • To make this global and real-time, connect a backend API
  • Current data is from this browser/device only

🔐 Security Note

This admin dashboard uses a simple password check. For production use, implement proper authentication.

📈 Next Steps

To enable global visitor tracking:

  1. Set up a backend API (Node.js, Python, etc.)
  2. Update CONFIG.apiUrl in script.js
  3. Implement email verification for real names
  4. Add database storage for persistent data
